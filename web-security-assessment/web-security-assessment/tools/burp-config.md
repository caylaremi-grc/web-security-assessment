# Burp Suite Configuration

## Proxy Configuration
- Browser traffic routed through Burp Suite proxy
- Default listener:
  - 127.0.0.1:8080

## Features Used
- Proxy HTTP History
- Repeater
- Intercept
- Request modification
- Intruder

## Usage
Burp Suite was used to:
- Intercept HTTP requests
- Modify parameters
- Test IDOR vulnerabilities
- Perform Path Traversal testing
- Analyze authentication behavior
- Perform username enumeration testing
- Perform password brute-force testing using Intruder
- Compare server responses, status codes, and response lengths
