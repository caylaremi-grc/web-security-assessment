# Scope

## Assessment Type
Web Application Security Assessment

## Scope
The assessment focused on identifying common web application vulnerabilities, including:
- SQL Injection
- UNION-Based SQL Injection
- Cross-Site Scripting (XSS)
- Insecure Direct Object References (IDOR)
- Cookie Manipulation
- Path Traversal
- User Enumeration
- Unrestricted File Upload/Download

## Testing Approach
Testing was performed manually using browser developer tools, HTTP interception tools, and crafted payloads to identify insecure application behavior.
