# Methodology

## Information Gathering
- Reviewed application functionality and user interaction points
- Identified input fields, parameters, cookies, and file handling features

## Vulnerability Testing
Manual testing was performed against:
- Authentication mechanisms
- Input validation
- Access control
- File upload/download functionality
- Session handling
- URL parameters and HTTP requests

## Tools Used
- Burp Suite
- Browser Developer Tools
- Custom payload lists

## Validation
Findings were validated by reproducing the behavior and confirming unauthorized or insecure functionality.
